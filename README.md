# 🚗 Road Assistance Management System

A full-stack **Road Assistance Management System** built using the **MERN stack**. The application helps users request roadside assistance and allows service providers to manage and respond to service requests.

## 📌 About the Project

The Road Assistance Management System provides a platform where users can request roadside assistance for vehicle-related problems and connect with available service providers.

The system is designed to make roadside assistance faster, easier, and more organized.

## ✨ Features

### 👤 User
- User registration and login
- Secure authentication
- User dashboard
- Request roadside assistance
- Manage vehicles
- Track service requests
- View service history
- Review and rate service providers
- Manage profile

### 🛠️ Service Provider
- Provider registration and login
- Provider dashboard
- Manage profile
- View service requests
- Accept and manage service requests
- View service history
- Track earnings
- Manage reviews

### ⭐ Reviews & Ratings
- Users can rate service providers
- Users can submit reviews
- Providers can view reviews
